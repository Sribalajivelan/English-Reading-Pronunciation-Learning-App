# ஆங்கிலம் படிப்போம் — English Reading & Pronunciation Learning App

A 30-day English reading and pronunciation course for Tamil speakers.
Single-file web app: open `index.html` in a browser (no build step).

- 30-day plan with task checklists, progress and streak
- A–Z letter sounds with Tamil guides and consonant + vowel drills
- Tap-to-hear words, patterns, sentences and short stories (browser speech synthesis)
- Listen and read quizzes with saved best scores

Progress is stored in the browser's localStorage.
